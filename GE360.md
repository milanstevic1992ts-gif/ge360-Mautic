# GE360 Mautic

GE360 Mautic is the marketing-automation component of the GE360 ecosystem.

The upstream Mautic source stays intact as much as possible. GE360-specific code lives in:

- `ge360/` — Docker deployment, bridge, backups and integration contracts.
- `plugins/Ge360IntegrationBundle/` — the Mautic-side GE360 plugin.

## Architecture

```text
Prospex ─────┐
             │
SuiteCRM ────┼── n8n / GE360 Bridge ── Mautic
             │                         │
Jarvis ──────┘                         └── campaigns / segments / forms
```

Default local ports:

- Mautic: `127.0.0.1:8793`
- GE360 Bridge: `127.0.0.1:8794`

See [ge360/README.md](ge360/README.md) for installation and operations.
